# Plasma Physics

## Electric Propulsion Theory

Electric thrusters (Hall, Ion) rely on ionizing gas (Xenon/Krypton) and accelerating ions.

### Ionization Rate
Expressed using the collision frequency:
$$\nu_{iz} = n_e \langle \sigma_{iz} v_e \rangle$$

### Debye Length
Defines the plasma shield thickness:
$$\lambda_D = \sqrt{\frac{\epsilon_0 k_B T_e}{e^2 n_e}}$$
